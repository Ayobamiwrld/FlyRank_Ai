# Flyrank Ai

Capstone: an AI assistant for students and professionals who lose time turning messy notes into a plan they can act on.

**Who.** People who capture notes faster than they can organise them.

**Problem.** Notes and task lists pile up. The bottleneck is rewriting them into a short, ranked plan—not capturing more text.

**Claim.** Flyrank Ai summarises notes, extracts tasks, and returns a plan so users spend less time rewriting and more time doing the work.

## Stack
- Next.js + TypeScript
- FastAPI (Python)
